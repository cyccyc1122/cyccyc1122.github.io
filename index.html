sg-rclone

A personal Google Drive synchronization tool operated by its owner using rclone on an owner-managed Linux server.

What the application does

  • Downloads Markdown documents from a selected Google Drive folder while preserving its directory structure.
  • Uploads completed files from a separate local results folder to a dedicated Google Drive results folder.
  • Checks for changes on a schedule and retains destination files when their source files are removed.

Google account access

The application requests Google Drive access so it can read existing documents and upload result files. Its configured transfer paths restrict its normal operations to the folders selected by the owner. The Google permission itself covers a broader set of Drive files than those configured paths.

This application is intended for its owner's personal use. These public information pages do not provide a Google sign-in form or accept documents, access tokens, or client secrets.

Contact

Use the owner's support email shown on the application's Google authorization screen for questions about this application or its data handling.
