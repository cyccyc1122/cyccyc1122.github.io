Privacy policy

Application: sg-rclone
Last updated: October 14, 2026

Purpose and operator

sg-rclone is a personal-use synchronization tool operated by its owner. It uses rclone and the Google Drive API to transfer selected documents between the owner's Drive account and an owner-managed server.

Data accessed and how it is used

The tool accesses file and folder names, identifiers, sizes, modification times, and other metadata needed to locate and compare files. It downloads Markdown file contents from the configured source folder and uploads completed files from a separate local results folder. It uses OAuth access and refresh tokens to authenticate these operations.

Sync logs may contain filenames, timestamps, transfer results, and error messages. The configured tool does not sell this data or use it for advertising.

Storage and service providers

Downloaded documents, local result files, sync logs, and authorization configuration are stored on the owner's server. Uploaded results are stored in the owner's Google Drive. Google and the server hosting provider supply the infrastructure used for these transfers and storage.

The owner may separately use other tools to work with the downloaded documents. Access granted to such tools is managed by the owner and is outside this synchronization application's transfer functions.

Retention and removal

Documents and saved historical versions remain until the owner removes them. The tool's copy operations do not automatically remove a destination file when its source is deleted. Sync logs are subject to configured log rotation and may also be removed by the owner.

The owner can stop synchronization, remove local files and authorization configuration, delete uploaded results from Google Drive, and revoke the application's access in Google account settings. Revoking access does not itself delete files already copied.

Public information pages

These pages contain application information only. They have no sign-in forms, document uploads, analytics scripts, or advertising. When published using GitHub Pages, the hosting provider records visitor IP addresses for security purposes, as described in GitHub's Pages documentation.

Contact

For questions about this application or requests concerning its data, use the owner's support email shown on the Google authorization screen.
